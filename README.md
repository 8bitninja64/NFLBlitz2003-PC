# NFL Blitz 2003 — PC port (static recompilation)

Work-in-progress native PC port of NFL Blitz 2003 (GameCube, USA). The game's PowerPC
executable is translated to C++ from **your own disc image** at build time; Nintendo SDK
functions are replaced by host implementations on [Aurora](https://github.com/encounter/aurora).

No game data is included. Status and build steps: see `CLAUDE.md`.
